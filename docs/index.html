Getting started

Install and first launch

Ready in under 30 seconds, with the whole source in the open.

1

Download the DMG

Get the universal binary: Apple Silicon and Intel, in a single DMG.

2

Drag it to Applications

Open the downloaded disk image and drag the copy4paste icon into your Applications folder.

3

Grant Accessibility permission

In System Settings > Privacy & Security > Accessibility, enable copy4paste so it can catch the global shortcut.



macOS Gatekeeper notice

The app is open source and not notarized by Apple, so macOS distrusts it the first time. It is the only warning you will see, and only once:

1. Right-click the app → Open.
2. On macOS 15 or later that button may be missing: go to System Settings → Privacy & Security and click “Open Anyway”.
Then grant Accessibility and you are set.
